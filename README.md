# GW2 ArcDPS TChinese UI

《激戰 2》（Guild Wars 2）國際版客戶端的 arcdps 插件：開啟內建簡體中文、轉成繁體顯示，並提供中文語音與中文輸入。

> **風險聲明**：本插件會修改執行中的遊戲客戶端（記憶體補丁、掛鉤）。這可能違反遊戲的使用條款，請自行評估並自負風險。作者沒有查證官方的現行政策。

## 功能

在 arcdps 選項視窗裡有五個按鈕：

| 按鈕 | 作用 |
|---|---|
| **開啟內建簡體中文** | 完整切換遊戲語言。交易行、寶石商城、魔法庫、兌換所等網頁也會是中文，並可被繁體化。**遊戲字型會改成為中國版本設計的字型。** |
| **簡體轉繁體模式** | 把遊戲內文字轉成繁體。勾選時自動開啟簡體中文；商城網頁繁體化跟著它。 |
| **中文語音（實驗）** | 把配音語言切成中文，並讓遊戲準備（檢查、補齊、登記）中文語音資源。 |
| **中文輸入增強** | 讓商城、交易行等網頁介面可以用系統輸入法打中文。 |
| **開啟內建簡體中文(舊)** | 只刷新介面文字，**遊戲字型不變**。商城等網頁維持英文，不會繁體化。**這是預設方式。** |

### 兩種簡體中文方式

「開啟內建簡體中文」與「開啟內建簡體中文(舊)」是同一件事的兩種做法，**互斥**（勾一個會換掉另一個）。取消後會記住最後用的方式，之後勾「簡體轉繁體模式」自動開啟簡體中文時沿用它；從沒選過就用舊方式。

| | 舊方式（預設） | 新方式 |
|---|---|---|
| 遊戲字型 | 不變 | 改成中國版本字型 |
| 商城等網頁 | 英文 | 中文，可繁體化 |
| 原理 | 只呼叫「語言已變更」處理函式 | 呼叫完整的 `SetLanguage`，遊戲儲存的語言變成簡體中文 |

新方式在切換語言**之前**會先解鎖文字語言（國際版客戶端預設不允許簡體中文，沒解鎖時進遊戲會斷言失敗而崩潰）。解鎖失敗時會自動退回舊方式並顯示原因。

### 簡體轉繁體模式

- 勾選時，若簡體中文尚未開啟，會自動開啟（用目前選的方式）；取消時**只還原由它自動開啟的那一份**，你自己先開的簡體中文會保留。
- 商城網頁繁體化**只有新方式才會載入**。舊方式下網頁是英文，沒有東西可轉。
- 網頁的搜尋框：你輸入繁體，網頁讀到的是簡體（伺服器與物品名稱都是簡體），畫面上顯示的仍是繁體。
- 使用與遊戲內相同的字典，沒有收錄的詞不會轉換。

### 中文語音（實驗）

1. 解鎖並切換配音語言。遊戲進入角色時會把配音改回帳號儲存的語言，所以勾選期間會自動重新套用。
2. 讓遊戲準備簡體中文語音資源。第一次可能需要下載大量檔案，進度會顯示在按鈕旁，顯示「資源已就緒」才完整。
3. 已實作「補齊途中關閉遊戲」的保護，但**取消進行中下載的那一段尚未在真實情境驗證過**，因此標為實驗。建議第一次補齊時等到完成再關閉遊戲。

### 中文輸入增強

遊戲建立內建瀏覽器時，在官方啟動腳本後面附加輸入法橋接腳本，並調整商城編輯框的聚焦、延遲組字期間的文字變更通知（這一項也會影響遊戲內其他原生輸入框）。勾選後要把商城、交易行**關閉再重新開啟**才會生效。

## 安裝

1. 安裝 [arcdps](https://www.deltaconnected.com/arcdps/)。
2. 把 `arcdps_tchineseui.dll` 放進遊戲資料夾的 `bin64`（與其他 arcdps 插件同一處）。
3. 進遊戲，在 arcdps 選項視窗找到上面的按鈕。

## 注意與限制

- **勾選狀態不會記住**，每次啟動遊戲都要重新勾。
- 切換任何選項後，**已經開啟的網頁要重新開啟**才會套用。
- 所有功能都靠特徵碼在遊戲程式裡定位位址，**遊戲大改版後可能失效**。找不到時該功能會停用並顯示原因，不會硬打補丁；詳細訊息在 arcdps 日誌 `addons\arcdps\arcdps.log`，以 `[Lang]`、`[Voice]`、`[IME]` 開頭。
- 圖片裡的文字無法轉換。
- 字典沒有收錄的詞（例如部分網頁用詞）會維持簡體；可以在 `Data\add.json` 補規則後重新建置。

## 建置

- Visual Studio（工具集 v143 / v145），平台 `x64`、組態 `Release`（靜態連結）。
- 相依套件由 vcpkg manifest（`vcpkg.json`）安裝：`imgui`、`minhook`、`nlohmann-json`、`asmjit`、`zydis`。
- 需要子模組：`git submodule update --init`（`external/arcdps-extension`）。
- 字典與腳本放在 `ArcDPS TChinese UI\Data\`，以相對路徑編進 `Resource.rc`。
- 輸出：`arcdps_tchineseui.dll`。
